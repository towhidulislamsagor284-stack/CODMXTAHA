#CODMXTAHA— Developer Portfolio

A free, responsive static portfolio made with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation, theme toggle and reveal animations

## Preview locally
Open `index.html` in a browser. You can also use the free Live Server extension in Visual Studio Code.

## Personalize before publishing
1. Replace the photo placeholder in `index.html` with your own image. Put the image in this folder, for example `assets/profile.jpg`, and use an `<img>` element with that path.
2. Replace the demo GitHub and Instagram URLs with your real profile URLs.
3. Replace `hello@codmxtaha.example` with your real email address.
4. Update the skills and project cards to reflect work you have actually completed.
5. Update the page title and description if you change the brand.

The contact section uses a mailto link, not a backend form. It opens the visitor's email app; no messages are stored by this website.

## Free publishing with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a public repository named `YOUR-USERNAME.github.io`.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. Open repository Settings → Pages and choose deploy from the `main` branch and `/ (root)` folder if it is not already enabled.
5. Your site will be published at `https://YOUR-USERNAME.github.io/`.

GitHub Pages is free for public repositories. The URL depends on your GitHub username; `codmxtaha.github.io` only works if that username is available and belongs to you.
